## What is in each folder

| File | What it is |
|---|---|
| `README.md` | The build guide, with images and the team's video clips |
| `*.pdf` | The same guide as a PDF, with every image included (videos appear as a frame and a link) |
| `<slug>.md` | The Circuit Digest CMS version, with the Quick Answer and Table of Contents blocks |
| `<slug>-shot-list.md` | Notes on every image and video: source, size, alt text |
| `index.html` | A local reading page; open it from a downloaded copy of the folder |
| `images/`, `videos/` | Diagrams drawn for the guide, the team's photos and their clips |

Values still missing in a guide are marked `[TODO: ...]`.
